命名规范

  • 风格：-outline（线框风格）/ 无后缀（填充风格）
  • 示例：book-outline.ico、shield-check-outline.ico、cactus.ico
  • 避免过长的复合名（如 account-search-outline 已是上限），同一概念尽量用最少的词表达

图标文件名须与 folder_icon.py 中 ICON_TO_TABLER 字典的 key 一致。

扩展图标：在 ICON_TO_TABLER 中添加映射："my-icon.ico": "tabler-icon-name"，然后在 icon_config.yaml 中使用。

脚本逻辑说明：

函数作用
get_svg()从 CDN 下载 Tabler SVG（或从本地读取）
svg_colorize()将 SVG 中 currentColor / stroke / fill 替换为目标 RGB 色
render_svg()将 SVG 渲染为 PNG（多尺寸：16/32/48/256px）
build_ico()将多尺寸 PNG 打包为 Windows .ico 文件
make_icon()组合以上步骤生成单个 .ico
write_desktop_ini()写入 desktop.ini（必须 ANSI 编码），IconResource 须为相对路径（如 .folder-icons\book-outline.ico），从子文件夹出发指向目标目录内的图标目录，设置 +S +H 属性
set_folder_system_attr()设置文件夹 +S System 属性（含空格路径必须加引号）

常见问题

Q: Skill 触发词不生效？

原因：Skill 放错目录了。必须放在 $env:USERPROFILE\.openclaw\skills\ 下，不是 workspace/skills/。

Q: desktop.ini 无效，图标不显示？

  1. 确认编码：Windows 要求 desktop.ini 必须为 ANSI 编码（非 UTF-8），Python 写入时须显式指定：

    若用 encoding='utf-8' 可能导致 Explorer 无法读取，图标不显示。

  2. 确认路径为相对路径：IconResource 须用相对路径而非绝对路径，例如：

    路径为从子文件夹出发指向目标目录内图标目录的相对路径。 绝对路径（如 D:\Icon\...）在目录移动或跨分区时失效，且不便于整体迁移。

  3. 确认文件夹有 +S 属性：attrib +S "D:\目标目录\文件夹名"

  4. 确认 desktop.ini 有 +S +H 属性：attrib +S +H "D:\目标目录\文件夹名\desktop.ini"

  5. 尝试手动刷新：powershell -Command "Rundll32 user32.dll,UpdatePerUserSystemParameters"

Q: 图标颜色不对？

配色逻辑仅替换 currentColor、stroke、fill，保留 stop-color（渐变）和 stroke="none"（透明）。某些 SVG 可能包含不受支持的额外颜色属性，需要调整 svg_colorize() 函数。

Q: 想要更多图标？

  1. 访问 https://pictogrammers.com/library/icon/ 选择图标
  2. 记下图标名（如 chart-bar）
  3. 在 folder_icon.py 的 ICON_TO_TABLER 中添加映射："chart-bar-outline.ico": "chart-bar"
  4. 在 icon_config.yaml 中使用该图标
