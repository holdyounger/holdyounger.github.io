X64 Windows 内核结构体详解

结构体层级 · 偏移速查 · 攻防视角 基于 WinDbg dt 输出 + WRK 源码

GS (x64)

用户态: Base=TEB 内核态: Base=KPCR

GS:[0x30]→TEB GS:[0x60]→PEB GS:[0x40]→PID GS:[0x48]→TID GS:[0x188]→ETHREAD(内核)

CR3

页表基地址

= KPROCESS.DirectoryTableBase = EPROCESS.Pcb.DirectoryTableBase

切换进程=切换CR3

🟢 用户态结构体

TEB (线程环境块)

每个线程一个 · 用户态可见

+0x00 NtTib.ExceptionList (x86 SEH) +0x08 StackBase ← GS:[0x08] +0x10 StackLimit ← GS:[0x10] +0x30 Self (自引用) ← GS:[0x30] +0x38 EnvironmentPointer +0x40 ClientId.PID ← GS:[0x40] +0x48 ClientId.TID ← GS:[0x48] +0x58 ThreadLocalStorage +0x60 PEB指针 ← GS:[0x60] +0x68 LastErrorValue ← GS:[0x68]

NT_TIB: ExceptionList / StackBase StackLimit / Self

自引用技巧: 不需要知道TEB地址 GS:[0x30]直接获取

KPCR / KPRCB

每CPU核心一个

KPCR (GS Base in kernel): +0x000 NT_TIB (与TEB重叠) +0x038 Gdt +0x040 Prcb → KPRCB +0x188 CurrentThread → ETHREAD

KPRCB: CurrentThread 当前线程 NextThread 下一线程 IdleThread 空闲线程 DPC队列 / 定时器 CPU运行队列

内核态获取当前线程: mov rax, gs:[0x188] → 直接得到 ETHREAD 指针 无需任何API调用

⚔️ 安全攻防视角

反调试技术汇总

PEB+0x02 BeingDebugged PEB+0x60 NtGlobalFlag (FLG_HEAP_ENABLE_TAIL_CHECK FLG_HEAP_ENABLE_FREE_CHECK FLG_HEAP_VALIDATE_PARAMETERS) EPROCESS+0x340 DebugPort 清零=反调试 ETHREAD+0x510 HideFromDebugger 线程对调试器隐藏 PEB+ProcessHeap HeapFlags 调试器修改堆标志

🔴 寄存器层

Shellcode 模块基址获取

; x64 获取 kernel32.dll mov rax, gs:[0x60] ; PEB mov rax, [rax+0x18] ; Ldr mov rax, [rax+0x20] ; InMemOrder mov rax, [rax] ; ntdll mov rax, [rax] ; kernel32 mov rax, [rax-0x10+0x30] ; DllBase

; 然后在导出表中 ; 搜索 GetProcAddress ; → GetModuleHandle ; → LoadLibrary A/W

GDTR / IDTR

GDTR→GDT 段选择子→段描述符 GS/FS基址来源

IDTR→IDT 中断向量→处理函数 系统调用入口

LDTR / TR

LDTR→LDT(基本不用)

TR→TSS x64: 内核栈指针 IST中断栈表

🟣 内核态结构体

PEB (进程环境块)

每个进程一个 · 用户态可见

+0x002 BeingDebugged 反调试 +0x008 Mutant +0x010 ImageBaseAddress 映像基址 +0x018 Ldr → PEB_LDR_DATA +0x020 ProcessParameters (命令行/路径/环境变量) +0x030 ProcessHeap +0x038 FastPebLock +0x060 NtGlobalFlag 反调试 +0x0B8 NumberOfProcessors +0x2C0 SessionId

RTL_USER_PROCESS_PARAMETERS: CommandLine / ImagePathName DllPath / Environment

反调试: BeingDebugged (PEB+0x02) NtGlobalFlag (PEB+0xBC) Heap Flags (ProcessHeap)

PEB_LDR_DATA

PEB+0x18 → 此结构

+0x010 InLoadOrderModuleList 按加载顺序 +0x020 InMemoryOrderModuleList 按内存顺序 +0x030 InInitializationOrderModuleList 按初始化顺序

三条双向循环链表 枚举所有已加载DLL/EXE

LDR_DATA_TABLE_ENTRY

链表节点 · 每模块一个

+0x000 InLoadOrderLinks +0x010 InMemoryOrderLinks +0x020 InInitializationOrderLinks +0x030 DllBase (模块基址) +0x038 EntryPoint (入口点) +0x040 SizeOfImage +0x048 FullDllName (完整路径) +0x058 BaseDllName (文件名)

Shellcode获取kernel32基址:

  1. GS:[0x60]→PEB
  2. PEB+0x18→Ldr
  3. Ldr+0x20→InMemoryOrderList
  4. 第3节点=kernel32
  5. 节点+0x20=DllBase

KTHREAD (内核线程块)

ETHREAD+0x000 第一个成员

+0x000 Header (调度器对象) +0x018 SListFaultAddress +0x020 QuantumTarget +0x028 InitialStack 栈底 +0x030 StackLimit 栈顶 +0x038 StackBase +0x040 ThreadLock +0x048 CycleTime +0x050 CurrentRunTime / +0x054 ExpectedRunTime +0x058 KernelStack 当前栈指针 +0x060 StateSaveArea (XSAVE_FORMAT) +0x068 SchedulingGroup +0x070 WaitRegister +0x074 MiscFlags +0x078 ApcState APC状态 +0x0F0 Teb → 用户态TEB +0x0F8 Timer +0x138 WaitBlockList +0x140 WaitListEntry +0x168 FreezeCount / ThreadFlags KernelStackResident / ReadyTransition ApcQueueable / Pageable +0x170 SpecialApcDisable +0x172 KernelApcDisable +0x178 TrapFrame → KTRAP_FRAME 保存用户态上下文 +0x180 Win32Thread +0x198 WaitStatus +0x1D0 PreviousMode 执行模式 +0x1D4 WaitTime +0x1D8 Priority 状态: 0=Init 1=Ready 2=Running 3=Standby 4=Terminated 5=Waiting 6=Transition +0x200 Process → KPROCESS +0x208 Affinity / +0x218 UserAffinity +0x240 Cookie / +0x244 IdealProcessor +0x248 ThreadListEntry

KPROCESS (内核进程块)

EPROCESS+0x000 第一个成员

+0x000 Header (调度器对象) +0x018 ProfileListHead +0x028 DirectoryTableBase = CR3 +0x030 ThreadListHead 线程链表 +0x038 ProcessLock +0x03C ProcessTimerDelay +0x040 DeepFreezeStartTime +0x048 Affinity (CPU亲和性) +0x058 ReadyListHead 就绪链表 +0x068 SwapListEntry +0x070 ActiveProcessors +0x080 ProcessFlags +0x084 ActiveGroupsMask +0x088 BasePriority +0x089 QuantumReset +0x08B Flags (KEXECUTE_OPTIONS) NX策略 / 执行选项 +0x08C ThreadSeed[1] +0x08E IdealProcessor[1] +0x090 IdealNode[1] +0x096 StackCount 内核栈计数 +0x098 ProcessListEntry +0x0A8 CycleTime CPU周期 +0x0B0 ContextSwitches 切换次数 +0x0B8 SchedulingGroup +0x0C0 FreezeCount +0x0C4 KernelTime / +0x0C8 UserTime +0x0CC ReadyTime +0x0D0 UserDirectoryTableBase +0x120 InstrumentationCallback +0x128 SecureState +0x130 KernelWaitTime / +0x138 UserWaitTime

切换进程时: CR3 ← KPROCESS.DirectoryTableBase

EPROCESS (执行体进程块)

内核进程核心结构

+0x000 Pcb (KPROCESS) ├── DirectoryTableBase = CR3 ├── ThreadListHead → ETHREAD └── Affinity / Priority +0x2D0 ProcessLock +0x2D8 CreateTime / +0x2E0 ExitTime +0x2E8 RundownProtect 进程停止保护锁 +0x2F0 UniqueProcessId (PID) +0x2F8 ActiveProcessLinks 进程链表 表头: PsActiveProcessHead PID=4 System进程为表头 +0x308 ProcessQuotaUsage[2] +0x310 ProcessQuotaPeak[2] +0x318 CommitCharge 已提交页面数 +0x320 PeakVirtualSize +0x328 VirtualSize +0x330 SessionProcessLinks +0x340 DebugPort 反调试 +0x348 ExceptionPortData +0x350 ObjectTable (句柄表) 层次结构 1~3层 最多 2^24 句柄 +0x358 Token (访问令牌) +0x380 ImageFilePointer → FILE_OBJECT +0x388 ImageFileName[15] +0x397 PriorityClass (idle/normal/high...) +0x398 VadRoot (VAD树) +0x3C0 Win32Process (GUI标志) +0x3C8 Job → EJOB +0x3D0 SectionObject +0x3F8 InheritedFromUniqueProcessId 父PID +0x448 Peb → 用户态PEB +0x4D0 ThreadListHead 线程链表 +0x530 Flags 进程状态标志 +0x534 ActiveThreads +0x538 Peb → 用户态PEB

⚠️ 偏移基于 Win10 22H2 (Build 19045)
