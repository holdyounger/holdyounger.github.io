下坠效果

通过计算桌面的宽度、高度，来设置动画的起始值和结束值。

抖动效果

获取界面的坐标，然后进行上、下、左、右坐标浮动，通过setKeyValueAt()来设置每一时刻的位置，实现抖动效果。

透明度效果

设置每一时刻的透明度值，动画结束时界面还原（透明度再为1）。
