概要

PDM (Python Dependency Manager) 和 Poetry 是当前最主流的两个 Python 包管理 / 依赖管理工具，均采用 pyproject.toml 规范。PDM 对标 npm 风格，Poetry 更接近传统 pip+virtualenv 体验。

PDM 官网： https://pdm-project.org
GitHub： https://github.com/pdm-project/pdm

初始化项目

交互式问答创建 pyproject.toml，选择 Python 版本并决定是否创建虚拟环境。

完成后会生成：

  • pyproject.toml — 项目元数据和依赖声明
  • pdm.lock — 锁定文件，需提交到版本控制
  • .pdm-python — 项目 Python 路径（不要提交）
  • .venv/ — 虚拟环境目录

其他常用命令

命令用途
pdm install安装所有依赖
pdm sync同步环境与锁文件（清理多余包）
pdm build构建分发包 (sdist + wheel)
pdm publish上传到 PyPI

pdm config配置 PDM 行为
pdm python install安装独立 Python 解释器

虚拟环境

Poetry 默认在 {cache-dir}/virtualenvs/ 下管理 venv。可配置 virtualenvs.in-project=true 改为项目内 .venv/。

运行命令

常用命令

命令用途
poetry install安装所有依赖（无 lock 时自动生成 lock）
poetry install --no-root仅安装依赖，不安装项目本身（非 package 模式）
poetry lock仅更新 lock 文件，不安装
poetry build构建分发包 (sdist + wheel)
poetry publish上传到 PyPI
poetry export导出 requirements.txt
poetry config配置项管理
poetry cache list列出缓存
poetry cache clear --all清空缓存
poetry version显示/更新版本号
poetry check验证 pyproject.toml 格式
