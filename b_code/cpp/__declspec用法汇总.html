概述

__declspec 是 Microsoft Visual C++ 特有的编译器扩展属性，用于向编译器/链接器传递额外的修饰信息。
语法：__declspec(attribute) 或 __declspec(attribute("message"))

[TOC]

基本语法

放置位置：紧跟类型声明或函数声明之前（或之后，取决于属性类型）。

常用属性

deprecated — 标记已弃用

标记函数/变量已过时，调用方编译时触发 C4996 警告，并显示自定义提示信息。

编译时输出：

warning C4996: 'Get360SafeProductType': Get360SafeProductType已经被AutoCheckProductType取代...

使用场景： API 演进、接口迁移、平滑下线旧函数，给调用方充足的缓冲期。

跨平台等价写法

  • C++14 标准属性（推荐）：[[deprecated("message")]]
  • GCC/Clang：__attribute__((deprecated("message")))

dllexport / dllimport — DLL 导入导出

控制符号是否从 DLL 导出，或从外部 DLL 导入。

惯用宏模式（推荐）： 通过预处理宏在导出/导入间自动切换

在 DLL 项目预处理器定义中添加 MYLIB_EXPORTS，调用方不定义此宏即可自动切换为 dllimport。

selectany — 允许多重定义

告知链接器：若同一符号出现在多个编译单元中，任取其一，其余丢弃（与 COMDAT 机制配合）。

被多个 .cpp 文件 #include 时不会产生重定义链接错误。

MSDN 原文说明

Tells the compiler that the declared global data item (variable or object) is a pick-any COMDAT (a packaged function). At link time, if multiple definitions of COMDAT are seen, the linker picks one and discards the rest. Selectany can be used in initializing global data defined by headers, when the same header appears in more than one source file.

直白翻译： 当在头文件定义全局变量，并且这个头文件被 include 多次时，可以用这个开关剔除由于多次 include 而产生的重定义错误。链接器会从多个编译单元中任选一个定义，其余丢弃。

典型场景： 在头文件中定义初始化的全局变量，避免手动在某个 .cpp 中单独定义。

noinline — 禁止内联

强制编译器不将该函数展开为内联，保留独立的函数调用。

使用场景：

  • 需要准确的调用栈（崩溃分析）
  • 函数体较大，内联反而增大代码体积
  • 与 __declspec(dllexport) 共用时确保符号可见

noreturn — 标记不返回函数

告知编译器该函数执行后不会返回（如调用 exit()、throw、死循环等），消除”控制流到达函数末尾”的误报警告。

跨平台等价写法

  • C++11：[[noreturn]]
  • GCC/Clang：__attribute__((noreturn))

align(n) — 内存对齐

指定变量或结构体的内存对齐字节数（必须是 2 的幂）。

跨平台等价写法

  • C++11：alignas(n)
  • GCC/Clang：__attribute__((aligned(n)))

naked — 裸函数（无编译器序言/尾声）

编译器不自动生成函数入口（push ebp / mov ebp, esp）和出口代码，函数体须全部用内联汇编手写。

使用场景： 函数 Hook、shellcode 编写、极致性能优化。
注意：仅支持 x86，x64 不支持 naked。

uuid("...") — 附加 GUID

为 COM 接口或类附加一个全局唯一标识符（GUID），配合 __uuidof() 使用。

novtable — 省略虚表指针初始化

用于纯抽象接口类，告知编译器不生成虚表初始化代码（构造/析构中），节省代码体积。

注意

不能直接实例化带有 novtable 的类，否则虚函数调用会崩溃。仅用于纯接口定义。

property — 伪属性（get/set 访问器）

为结构体/类成员定义 getter/setter，使其像普通字段一样被访问（仅 MSVC 支持）。
