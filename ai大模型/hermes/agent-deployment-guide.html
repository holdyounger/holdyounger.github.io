项目简介

Hermes Agent 是由 Nous Research 开发的开源自主 AI 代理（MIT 许可证），其核心设计理念是”一个与你共同成长的 Agent”。

核心特性

特性说明
🧠 自我学习循环从经验中创建技能、在使用中改进技能、主动持久化知识
🌐 多平台网关支持 Telegram、Discord、Slack、WhatsApp、Signal 等消息平台
🛡️ 真沙箱隔离6 种代码执行后端（Local、Docker、SSH、Daytona、Singularity、Modal）
🎙️ 语音模式支持终端语音输入和消息应用语音消息
⏱️ 自然语言定时任务用自然语言描述调度计划（如”每天上午 9 点检查日志”）
⚡ 委派与并行可生成子代理并行工作，或通过 RPC 调用自己的工具
🔌 插件系统通过放入 Python 文件扩展功能
📱 模型无关支持 OpenRouter（200+ 模型）、Anthropic、Vercel AI Gateway、本地 LLM

为什么选择 Hermes

  • 24/7 无人值守自动化：监控服务器、解析数据、测试代码、编写报告
  • 告别”土拨鼠之日”：自动读取历史日志，已了解你的技术栈和项目上下文
  • 安全的代码执行：在隔离沙箱中执行 AI 生成的代码，保护系统安全

系统要求

支持的操作系统

系统支持状态说明
Linux✅ 完全支持Ubuntu 22.04 推荐
macOS✅ 完全支持通过 Homebrew 安装依赖
WSL2✅ 完全支持Windows 用户推荐使用 WSL2（Ubuntu 22.04）
Windows 原生❌ 不支持需使用 WSL2 或官方 Windows 安装器

⚠️ 重要提示：Hermes Agent 不支持 Windows 原生环境。Windows 用户请使用 WSL2（推荐 Ubuntu 22.04） 或官方 Windows 安装器。

安装过程说明

安装脚本会自动完成以下操作：

  1. 克隆仓库（包含所有子模块）
  2. 安装运行时依赖：

  3. 创建虚拟环境
  4. 安装 Python 依赖
  5. 设置全局 hermes 命令
