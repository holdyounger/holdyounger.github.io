条件要求

操作系统macOS / Linux / Windows
其他依赖Git（源码安装）、bun/npm（WebUI 构建，可选）

⚙️ 首次配置

初始化工作区

关键路径

路径说明
~/.nanobot/config.json实例配置（providers、channels、tools、gateway 等）
~/.nanobot/workspace/Agent 工作区（memory、sessions、cron jobs、skills）
<workspace>/sessions/*.jsonl会话历史（JSONL 格式）
<workspace>/memory/MEMORY.md长期记忆文件
<workspace>/cron/jobs.json定时任务存储
<workspace>/SOUL.mdAgent 身份定义文件

配置 AI Provider（config.json 片段）

支持的 Provider

Provider Key说明
openaiOpenAI 官方
anthropicClaude 系列
openrouterLLM 路由网关（推荐入门）
azure_openaiAzure 部署
bedrockAWS Bedrock
ollama / vllm本地 LLM
xai_grokGrok（X.ai）
github_copilotGitHub Copilot OAuth
custom任意 OpenAI-compatible 端点
stepfun、xiaomi_mimo 等中国市场特有

🐛 常见问题

问题原因解决方案
nanobot 不在 PATHuv tool 安装后未添加到 PATH按提示执行 export PATH=... 或重开终端
externally-managed-environment 报错pip 受系统保护改用 uv tool install nanobot-ai 或 pip install --break-system-packages
Windows WebUI 启动失败缺少 bun/npm安装 Node.js 后重试，或直接用 CLI 模式
