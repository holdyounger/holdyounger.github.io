3️⃣ 需要监控的指标清单

训练阶段

✅ 训练 Loss     → 应该在稳步下降
✅ 训练 Accuracy  → 应该在逐步上升
✅ 学习率         → 应该按计划衰减
✅ GPU 利用率    → 应该有 70%+（否则 DataLoader 慢）
✅ 显存使用量    → 不能爆显存

验证阶段

✅ 验证 Loss     → 与训练 Loss 差距不应太大
✅ 验证 Accuracy  → 与训练 Accuracy 的差距 = 过拟合程度
✅ 梯度范数      → 太大 => 梯度爆炸，太小 => 梯度消失
